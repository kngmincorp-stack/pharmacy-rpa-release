# PharmacyRPA 配布用（非公開）

このリポジトリは、薬局向けソフト「処方入力RPA（PharmacyRPA）」の **配布ファイル（exe）だけ** を置く非公開の場所です。
ソースコード・資料・データは置いていません。

- 各リリースに `PharmacyRPA-<版>.zip`（本体の exe・_internal・説明書だけ）、`PharmacyRPA-<版>.zip.sha256`（確認用の値）、
  `PharmacyRPA-<版>.zip.sig`（Ed25519 の署名）があります。
- 本体は、設定タブの［更新を確認］から、読み取り専用の合鍵でこのリリースを読み、署名と確認用の値が合った時だけ入れ替えます。
  確認とダウンロードは読み取りだけで、患者の情報・記録・設定は送りません。
- zip には患者のデータ（初期データ）・鍵は入っていません。
